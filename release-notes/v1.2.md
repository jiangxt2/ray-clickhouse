# ray-clickhouse 1.2

## Highlights

- Add opt-in reads from local shards behind eligible Distributed tables.
- Push supported Dataset column selections and predicates into table reads.
- Improve schema discovery for explicitly selected columns and add bounded client diagnostics.

## Compatibility

- Python 3.10 through 3.13 and final Ray releases `>=2.55,<2.60`.
- PyArrow `>=19,<20` and `clickhouse-connect[arrow] >=1.5,<1.6`.
- Predicate pushdown is limited to the documented expressions and verified Ray versions.
- Local-shard reads require the documented topology, permission, and consistency conditions.

## Validation

- The supported Python/Ray matrix, package checks, and ClickHouse integration run in CI.
- Multi-node profiles cover ClickHouse 23.3, 24.8, and 26.8 with Ray 2.59.

## Scope

Reads across multiple tasks do not share a database snapshot. Existing write, retry, and
ambiguous-outcome boundaries continue to apply.
