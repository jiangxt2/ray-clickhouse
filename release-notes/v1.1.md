# ray-clickhouse 1.1

## Highlights

- Support final Ray releases through the 2.59.x line.
- Add Python 3.10 through 3.13 unit, public-contract, and package checks on Ray 2.59.0.
- Validate the ClickHouse 26.8 profile with a Ray 2.59.0 multi-node integration run.
- Keep the existing structured read and append-write API and its fail-closed error boundaries.

## Compatibility

- Python 3.10 through 3.13.
- Final Ray releases `>=2.55,<2.60`.
- PyArrow `>=19,<20` and `clickhouse-connect[arrow] >=1.5,<1.6`.
- The pinned integration profile uses ClickHouse 26.8.1.2041 and Ray 2.59.0.

## Validation

- Unit, public-contract, and package checks passed on the supported Python/Ray matrix.
- ClickHouse 26.8 integration and the Ray 2.59.0 multi-node suite passed against this
  implementation.
- Wheel and source archive checks and installed-package smoke tests passed.

## Scope

This release adds Ray 2.59.0 compatibility. It does not change the connector's read,
write, retry, transaction, or table-management guarantees.

Previous version: 1.0.
